# 문장 규칙

화면과 보고서의 모든 문장에 적용합니다. 이 도구의 신뢰는 "확인되는 것만 말한다"에서 나옵니다.

## 써도 되는 문장 / 쓰면 안 되는 문장

| 써도 됨 | 쓰면 안 됨 | 이유 |
|---|---|---|
| 입금 후 보낸 주소로 다시 보낸 기록은 확인되지 않았습니다 | 받은 돈을 쓰지 않았습니다 | 이더리움은 받은 돈과 원래 잔액이 합쳐져 구분할 수 없음 |
| 입금 10분 뒤 다른 주소로 0.3 ETH를 보냈습니다 | 받은 돈을 다른 곳으로 옮겼습니다 | 시간 순서만 말할 수 있음 |
| 조회한 제재 목록에서 일치하지 않습니다 | 제재 주소가 아닙니다 | 목록에 없다고 안전한 주소는 아님 |
| 조회한 기록에서 이전 직접 거래는 확인되지 않았습니다 | 보낸 사람과 아무 관계가 없습니다 | 온체인 밖 관계는 알 수 없음 |
| 보낸 주소는 입금 전후 24시간 동안 34개 주소에 비슷한 금액을 보냈습니다 | 먼지 공격입니다 | 정황이지 판정이 아님 |

## 쓰지 않는 말

결백, 무관, 깨끗한, 안전한, 범죄와 관계없는, 증명됨

## 구분해서 쓰기

| 구분 | 표시 이름 | 코드 값 |
|---|---|---|
| 온체인에 그대로 있는 사실 | 확인된 기록 | `verified` |
| 기록을 세거나 비교해서 나온 것 | 분석한 정황 | `derived` |
| 사용자가 직접 답한 것 | 사용자 설명 | `UserStatement` |
| 원래 알 수 없거나 조회 범위 밖인 것 | 확인할 수 없음 | `unverifiable` |

- 사용자 설명과 온체인 기록을 한 문장에 섞지 않습니다.
- "확인할 수 없음" 항목에는 "온체인 기록으로 확인할 수 없는 내용입니다"처럼 이유를 적습니다.

## 숫자를 쓸 때

- 분모를 같이 씁니다. "34개 주소"가 아니라 "보낸 전송 40건 중 34개 주소"처럼 씁니다.
- 조회가 상한에 걸렸으면 "최대 1,000건까지 조회한 범위에서"를 붙입니다.
- 기간은 입금 시각 기준으로 씁니다. 예: "입금 전후 24시간"

## 출처

확인된 기록과 분석한 정황에는 원본 링크(거래 해시나 이더스캔 주소)를 최소 1개 붙입니다.
